# 🚀 ORBIX AI

### Interactive 3D Solar System with Hand Gesture Control

ORBIX AI is an interactive 3D Solar System project that allows users to explore and interact with a virtual space environment using hand gestures through a webcam.

## 🌌 Project Overview

The project combines 3D graphics and computer vision to create a hands-free interactive experience.

## ✨ Features

- Interactive 3D Solar System visualization
- Webcam-based hand tracking
- Gesture-based scene interaction
- Real-time visual feedback

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Three.js
- MediaPipe
- Webcam Integration

## ⚙️ How It Works

1. Open the ORBIX AI website.
2. Allow webcam access.
3. Start hand tracking.
4. Use supported hand gestures to interact with the 3D environment.

## 🎯 Project Focus

- Human–Computer Interaction
